# Soaiba Nuzhat — Portfolio

A personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build -- --webpack
```

The site is statically exported to `out/`.

## Deployment

Pushes to the `main` branch automatically deploy through GitHub Actions to
GitHub Pages. In the repository’s **Settings → Pages** screen, set the source
to **GitHub Actions**.
